# Hachikō — Biography Website

A minimalist biographical website dedicated to Hachikō, the legendary Akita dog of Japan.

## About

This project presents the story and legacy of Hachikō through a clean, minimalist design inspired by historical biography websites.

Hachikō became widely known for returning to Shibuya Station for years after the death of his owner, Hidesaburō Ueno.

## Features

- Minimalist and responsive design
- Hero section with Hachikō's portrait
- Biography section
- Historical timeline
- Dedicated footer section
- Japanese typography and visual elements

## Built With

- HTML5
- CSS3
